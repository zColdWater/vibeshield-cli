Why (SELECT auth.uid()) Matters

      
Calling bare auth.uid() inside a policy forces PostgreSQL to invoke the JWT function per row. Wrapping it in (SELECT auth.uid()) triggers an initPlan cache so Postgres evaluates it once per query.
